1. Structure de base

Lorsque le code JavaScript se trouve dans un fichier séparé (extension .js), la structure est la suivante :

/* zone d'en-tête */ /* déclaration des variables globales */ let Declaration1; /* CORPS DU PROGRAMME */ Instruction1;

2. Les commentaires

Ils ne sont pas interprétés par le navigateur et servent à documenter le code.

  • // indique un commentaire sur une ligne.
  • /* .... */ permet des commentaires sur plusieurs lignes.

3. Déclaration de variables

JavaScript est "faiblement typé". Une variable est déclarée avec var, let, ou const.

  • var : portée globale.
  • let : portée locale (recommandé).
  • const : pour déclarer une constante qui ne changera pas.

4. Les différents types

Le JavaScript possède plusieurs types de données :

  • Number : entiers et réels.
  • String : chaînes de caractères.
  • Boolean : true ou false.
  • Null / Undefined : absence de valeur.

5. Les opérateurs

Il existe les opérateurs arithmétiques (+, -, *, /, %, **), logiques (!, &&, ||, ==, !=, <, >) et d'affectation (=, +=, ++, --).

6. Fonctions d'entrée/sortie

Dialogue basique avec l'utilisateur :

  • window.alert("Message");
  • window.prompt("Question", "Défaut");
  • window.confirm("Êtes-vous sûr ?");
