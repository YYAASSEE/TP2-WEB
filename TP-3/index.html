EXERCICE 2 : Le langage SQL

Définition du SQL

Le SQL (Structured Query Language) est le langage standard utilisé pour interagir avec les bases de données relationnelles. Il permet de définir, manipuler et gérer les données.

Inventé dans les années 70 chez IBM suite aux travaux de Mr Codd sur le modèle relationnel, il a été officiellement standardisé en 1986.

Les normes de référence

Pour assurer une compatibilité entre les différents systèmes (Oracle, MySQL, PostgreSQL), plusieurs normes ont été publiées :

  • La norme SQL 89
  • La norme SQL 92
  • La norme SQL 2011

Conformité des systèmes

"Le développement de PostgreSQL respecte le standard en vigueur, tant que celui-ci ne s'oppose pas aux fonctionnalités traditionnelles ou au bon sens."
